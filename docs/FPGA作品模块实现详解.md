# FPGA 竞赛作品——模块实现详解

> 匿名参赛团队　|　文档日期：2026-11-03
> 本文件介绍作品的每一个功能模块「做什么、怎么实现、关键参数」，配套顶层结构图和数据流说明。

## 一、作品简介

**作品名**：基于 FPGA 的实时运动目标检测与图像处理系统

**硬件平台**：
- FPGA：安路 PH1P35（合封 DDR2 800Mbps，usr_clk 100MHz）
- 摄像头：SC500CS（500 万像素 CMOS，MIPI CSI-2，2 lane，配置为 1280×720@60）
- 显示：HDMI 720P60 输出
- 存储：片外 DDR2 帧缓存（4 块乒乓 + 背景帧）
- 交互：SW1~SW4 拨码开关、3 个按键、8 位数码管

**核心功能**：
1. **实时运动目标检测**：背景差分法，消隐期整帧读取当前帧与背景帧逐像素比较，前景 1bit/像素标记存入片内 ERAM
2. **形态学去噪**：3×3 开运算（先腐蚀后膨胀），滤孤立噪点、恢复目标尺寸
3. **目标框定**：外接框四边界 + 质心坐标 + 运动速度向量
4. **区域填充**：扫描线填充，把目标内部空洞填实
5. **三种图像算法**：灰度化 / 二值化 / Sobel-Canny 边缘检测（按键循环切换）
6. **自动曝光/增益**：亮度统计闭环调节，手动自动共用同一寄存器
7. **阴影抑制**：亮度+色度双重判据滤除光照阴影
8. **亮度自适应差分阈值**：按平均亮度分 4 档查表

## 三、数据流总览

三条主链 + 一条交互链：

| 链 | 路径 | 时钟域 |
|---|---|---|
| 视频输入链 | 摄像头 → MIPI → ISP → 写 DDR | 摄像头域（~75M）→ DDR 域（100M） |
| 处理显示链 | DDR → 背景差分链 → ERAM → OSD → HDMI | DDR 域 → HDMI 域（74.25M） |
| 背景读链 | DDR → bg_read（消隐期）→ 差分 → 前景标记 | DDR 域 |
| 交互链 | 按键/拨码 → 参数模块 → 数码管 | 24M 域 |

**关键设计：背景读独占消隐期**。HDMI 720P60 一帧 16.6ms，其中场消隐期 4.26ms。bg_read 在消隐期内读满当前帧+背景帧（336000 拍 × 10ns = 3.36ms），显示期 DDR 完全归还给显示读和采集写，三路天然错峰。

## 四、模块详解

### 4.1 视频输入链（MIPI → ISP）

#### 4.1.1 lane_lvds_10_1 + ph1p_mipiio_rx_wrapper（官方 IP）

- **功能**：MIPI D-PHY RX 物理层。LVDS 差分信号转单端 10bit，HS/LP 检测，字节对齐（byte_aligner）、通道对齐（channel_aligner，2 lane 同步）。
- **思路**：官方 IP 黑盒（.enc.v 加密），时钟恢复由 PLL 提供，输出 16bit/拍（2 lane × 8bit）给 CSI 解包。

#### 4.1.2 csi_unpacket_2lane / raw10_unpacket_2lane（官方）

- **功能**：CSI-2 协议层解包。剥离包头/ECC/CRC，从 2 lane 字节流恢复 RAW10 像素流；raw10 解包把 10bit 像素拼回字对齐。
- **输出**：RAW10 像素（4 像素打包）进入 ISP。

#### 4.1.3 bad_pixel_correct（坏点校正，自研）

- **思路**：3×3 邻域极值检测。中心像素若比 8 邻域同通道值都大/都小且差值超阈值 → 判为坏点，用邻域同通道值替换；否则原样输出。**只替换真坏点，不糊正常边缘**（与整帧中值滤波本质区别）。
- **实现**：R/G/B 三通道独立校正，各自走 2 行 line buffer（与灰度链同构）；4 像素并行，跨组边界左邻居缓存上一组 g3、右邻居复制 g3；总延迟 3 拍。
- **背景**：传感器坏点簇漏电流大，增益放大后呈白点（位置固定、随增益变亮，实机已坐实）。

#### 4.1.4 demosaic_4x_2_0（去马赛克，官方改进）

- **功能**：Bayer RAW → RGB888。双线性插值（bilinear_interpolation），line_buffer_demosaic 攒 3 行 3×3 窗口，raw_matrix_3x3_buffer 输出窗口矩阵。
- **思路**：4 像素并行处理，line buffer 用 BRAM 硬核（只在 valid 时递增地址、消隐期冻结，天然对齐「上一行」）。

#### 4.1.5 awb（自动白平衡，官方）

- **功能**：RGB 增益校正，输出 96bit（4 像素 RGB888）。

#### 4.1.6 gray_convert（灰度化）

- **功能**：RGB888 → 灰度。`gray = (R>>2) + (G>>1) + (B>>2)`，4 像素各算各的，输出每像素 R=G=B=gray 拼回 96bit。
- **定位**：后续所有算法（亮度统计/二值/Sobel/Canny/背景差分）的公共输入。

#### 4.1.7 brightness_stat（亮度统计）

- **功能**：累加一帧灰度总和，帧末输出平均亮度 O_avg（0~255）；每 40 帧输出一个调节脉冲 O_adjust。
- **用途**：自动曝光闭环的反馈量（跨时钟域在 ae_set 内部打两拍同步）。

#### 4.1.8 binary_convert（二值化）

- **功能**：灰度图按阈值二值化，阈值 S_threshold（0~255，初始 60）由按键调节。

#### 4.1.9 sobel_top（Sobel 边缘检测）

- **实现**：line buffer 级联 2 个攒三行 → 3×3 卷积算 Gx/Gy → 幅值 |Gx|+|Gy| → 阈值比较输出黑底白线。
- **细节**：4 像素并行，g3 右邻居「复制 g3」近似；边界前两行/最后一行、首尾组输出屏蔽。
- **阈值**：11bit 域 0~2040（初始 512，步进 64/长按 tick），实际比较用 mag8 域（阈值>>3）。

#### 4.1.10 canny_top（Canny 边缘检测，自研升级版）

- **思路**：Canny = Sobel + 非极大值抑制（NMS）+ 双阈值，把 Sobel 粗边缘细化为 1 像素细边缘。
- **实现流水**：
  1. **高斯滤波**：3×3 核 [1 2 1; 2 4 2; 1 2 1]，sum>>4（除以 16）去噪
  2. **Sobel 卷积**：Gx/Gy/幅值/方向
  3. **方向量化**：|Gy|>2|Gx|→垂直、|Gx|>2|Gy|→水平、否则按 Gx/Gy 同号判 45°/135°（2 倍近似 tan67.5°≈2.414）
  4. **NMS**：沿梯度方向比较 2 邻居，非局部极大清零
  5. **双阈值**：高阈值判强边缘，低阈值滤弱边缘
- **边界屏蔽**：h_cnt 3~318 组、v_cnt 8~711 行（卷积链左邻居依赖扩散 3 组，屏蔽前 3 组）。
- **已知边界伪影**：左边界第 4 组附近有断续虚线（依赖实际扩散层级，见「关键设计决策」待办）。

#### 4.1.11 median_filter（3×3 中值滤波）

- **功能**：Sobel 前级去噪。3×3 窗口 9 值取中值，滤椒盐噪点。
- **理由**：降阈值会引入噪点，中值滤波滤孤立噪点只留真边缘。

### 4.2 帧缓存与 DDR 仲裁

#### 4.2.1 video_in / video_out（写/读 DDR）

- **功能**：ISP 输出跨时钟域（摄像头→DDR）写入 DDR；DDR 读回跨时钟域（DDR→HDMI 像素时钟）送显示。
- **乒乓机制**：4 块缓冲区，写第 N 块时 video_out 读第 N-2 块，读写不冲突。读指针 I_video_out_rp 选块。

#### 4.2.2 ser_arbiter（三路串行仲裁）

- **功能**：单路 DDR 三通道（采集写/显示读/背景读）严格分时。
- **实现**：写批 → 显示读批 → 背景读批轮转，每个状态服务一个完整 burst；**批未完成（busy 未降）绝不切换**——命令流严格串行、无交织、无在途拖尾。
- **切换条件**：批完成（busy 下降）或本通道无批（1 拍跳过）；**超时保护**：批服务超 256 拍强制切换（防 ready 异常死锁）。

#### 4.2.3 ph1p35_324_ddr_wrapper（DDR2 控制器）

- **功能**：DDR2 控制器 + PHY（官方例化）。实际运行 800Mbps（tCK 2500ps 固化，usr_clk 100MHz）。
- **教训记录**：DDR 参数真载体是 ddr2.v 的例化参数（.params 文本无效）；改参数必须验证 phy 日志 SYN-8411=0 且 derive_clocks 成功。

### 4.3 背景检测链（核心自研）

#### 4.3.1 bg_read（消隐期整帧读 + 背景差分）

- **功能**：HDMI 场消隐期（4.26ms）内从 DDR 读「当前帧 + 背景帧」整帧，逐像素差分，前景标记打包写入片内 ERAM。
- **整帧读设计（2026-11-02 合并 bug 会话方案，根治细线撕裂）**：
  - 读满 336000 拍（700 行 × 480 拍/行）= 3.36ms < 4.26ms 消隐期
  - 显示期完全禁 bg 读（`S_vo_room = I_disp_win ? 0 : 1`），DDR 归还显示
  - 读满 700 行后 DRAIN 700 拍排空写链（主线 morph 链 645 拍 + row_fill 后原 644 窗口排不净，行 699 漏写——tb 对照 bug 会话原版锁定后扩窗）
  - 底部 700~719 共 20 行为放弃区（不更新前景标记，显示为不涂白——设计取舍，损失 2.8% 画面高）
- **差分判据**（前景 = 任一通道差超阈值）：
  - 亮度阈值按平均亮度分 4 档：avg<80→20、80~139→32、140~199→40、≥200→50（亮度高→像素波动大→阈值随亮度涨，自然光噪声对症）
- **阴影抑制 v3（相对色度容忍）**：
  ```
  shadow = (dy < -48) && (dy > -280)      // 亮度变暗且在一定范围
         && (ds <= 0)                     // 色度不升（无符号陷阱规避：有符号比较）
         && (|ds| <= 4 + s_bg/4)          // 色度变化 ≤ 容忍值（随背景色度放宽）
  ```
  真影子滤除、深肤色手（色度升）永不滤、灰色水管挡光（ds≈0）仍滤。
- **写侧**：前景 1bit/像素 → 40bit/字（4 像素×10 组打包），写地址帧头复位 0，700 行封顶 22399 字。
- **fg_init 判据**：写地址 ≥ 22080（行 690）即认为整帧前景就绪 → 显示叠加使能。整帧读后原 22920 判据永远到不了（fg_init 恒 0 涂白全灭的根因，已修）。
- **亮度自适应档位**：S_avg_d2（DDR 域打 2 拍）分档查表输出 thr_sel。

#### 4.3.2 morph_filter（形态学开运算）

- **功能**：1bit 前景标记（4 像素/拍）先腐蚀后膨胀：腐蚀滤孤立噪点（背景白斑），膨胀恢复目标尺寸。
- **实现**：可分离 4 级——3×1 水平腐蚀 → 1×3 垂直腐蚀 → 3×1 水平膨胀 → 1×3 垂直膨胀。
  - 垂直级用两级 320 深环形缓冲（DRAM 实现）：mem_v1 读 = 320 拍前（中心行）、mem_v2 读 = 640 拍前（上行）
  - 总延迟 644 有效拍，valid 用 18bit 有效拍计数（帧清清零，省 626 FF）
- **位序对齐**：valid 链 644 位与数据延迟严格同拍（历史上 valid 642 深错位 1 组 4 像素，上板手边缘列状错位的根因，已修）。
- **边缘提取**：形态学梯度 = 开运算 XOR 腐蚀（dil_v ^ ero_v），输出目标外轮廓线（2 像素宽环），单点噪点完全消失。
- **资源**：行缓冲 + 对齐链全部 DRAM 化（ram_style=dram 环形缓冲，写 mem[wp]、读 mem[wp+1] 恒错开），slice 超限修复。

#### 4.3.3 bbox_stat（外接框/质心/速度统计）

- **功能**：对写进 ERAM 的前景标记流做整帧统计：min_x/max_x/min_y/max_y（外接框）、sum_x/sum_y/cnt（质心累加）、相邻帧质心差分 = 速度向量。
- **数据源**：bg_read 写流三件套（O_fg_wr_en/addr/data），地址自带行号（addr>>5），每 10 拍处理一次（4px/拍流的攒字节奏），零额外存储。
- **流水化**：写拍锁存 → 拍 B 统计项锁存 + 乘法（拆长组合路径）→ 拍 C 入块；帧末（I_fs_pulse）段锁存 + 三段合并（A/B1/B2，交界区只由前段统计零重复）。
- **块密度过滤**：画面分 16×9=144 块，块内点数 < BLK_MIN=5 的块不进统计（滤误检）；帧末锁存有效块图，下一帧只收有效块内点。
- **质心除法**：div31 恢复余数除法器，sum/cnt → 质心坐标（商宽 11bit，x/y 分时复用单实例）。

#### 4.3.4 row_fill（行填充——区域填充功能）

- **功能**：对 1bit 前景标记做水平扫描线填充：每行按 0 游程分段（多段语义），段内 [L,R] 全 1、段外原值——手掌心空洞变实心，远处物体与手之间宽间隙不会误连。
- **多段参数**：
  - 段分割：0 游程 > GAP_T=10 组（40px）→ 断段；gap ≤ 40px → 段内空洞照填
  - 段宽过滤：段内 1 像素数 < MIN_W=4px → 整段不填（孤立噪点段兜底）
  - 每行最多 K=4 段（段表寄存器，行末锁存）
- **局限**：行级判定无垂直连通（横向目标好、纯纵向细条效果弱），已知取舍。

#### 4.3.5 fg_mark_eram（前景标记片内 ERAM）

- **功能**：40bit × 23040 深真双口 ERAM，存全帧前景标记（1bit/像素 × 1280×720 = 921600bit）。
- **双口**：A 口（DDR 域 100M）消隐期写前景标记；B 口（HDMI 域 75M）显示期读前景标记。
- **布局**：每行 1280 像素 = 32 字（1280/40 整除），整帧 720×32 = 23040 字；字地址 = y*32 + w；字内 bit0 = 字最左像素。
- **资源**：ERAM「512×40」配置，23040 = 45×512 精确整除 → 恰好 45 块零浪费。

### 4.4 显示与 OSD

#### 4.4.1 uivtc（视频时序控制器）

- **功能**：生成 HDMI 720P60 时序（vsync/hsync/de），74.25MHz 像素时钟。

#### 4.4.2 hdmi_mixer（OSD 叠加）

- **功能**：HDMI 时序与 DDR 读出的像素对齐；OSD 叠加：前景涂白（读 ERAM 前景标记）、外接框线、质心点、阈值/曝光等文字、Logo。
- **叠加门控**：`I_fg_init && sw4_2d && ...`——fg_init（整帧前景就绪）未置位时涂白/框全灭。
- **显示模式**：disp_mode 三态（区域填充模式 KEY4 循环）：0=涂白（填充后）→1=边缘→2=原图。

#### 4.4.3 osd_char_lib / osd_cn_char（字符字库）

- **功能**：ASCII + 中文点阵字库 ROM，OSD 文字显示用。

#### 4.4.4 hdmi_tx / hdmi_1_4b_transmitter_core_wrapper / hdmi_phy_warpper

- **功能**：HDMI 发送链路：TMDS 编码 → 并串转换 → PHY 差分输出（官方 IP）。

### 4.5 交互与参数配置

#### 4.5.1 debounce / key_pulse / key_hold（按键链）

- **debounce**：按键消抖 20ms（24MHz 计数）。
- **key_pulse**：单击脉冲（按键按下沿输出 1 拍脉冲）。
- **key_hold**：长按 tick——按住期间每 200ms 输出一个 tick 脉冲（持续调节）。

**按键映射**（硬件 4 键，I_button 3 键）：
- KEY1：系统复位（接复位脚，不进 I_button）
- KEY2（I_button[0]）：加（长按 tick 200ms）
- KEY3（I_button[1]）：减（长按 tick 200ms）
- KEY4（I_button[2]）：算法画面切换（单击循环：原样→灰度→二值→Sobel，仅原样模式 SW3SW4=00 生效）

#### 4.5.2 algo_mode_sel（算法模式循环）

- **功能**：KEY4 每按一次算法画面 +1 回绕：0=原样 → 1=灰度 → 2=二值 → 3=Sobel（S_algo_mode 选 ISP 算法输出）。
- **en 使能**：仅原样模式（SW3SW4=00）生效；检测模式（01/10/11）锁算法=原样——否则差分对 Sobel/灰度图 → 全图全白，且切回原样时画面错位。
- **与 SW12 的区别**：SW1/SW2 选「模式 0~3」= 数码管显示档 + 参数调节对象；KEY4 选「算法画面」= 显示哪种图像算法结果。两者独立。

#### 4.5.3 disp_mode_sel（显示模式三态）

- **功能**：区域填充模式下按键[2] 循环：0=涂白 → 1=边缘 → 2=原图；非填充模式锁定 0。

#### 4.5.4 threshold_set / sobel_threshold_set / target_set（参数寄存器）

| 模块 | 调节对象 | 范围 | 初值 | 步进 | 使能条件 |
|---|---|---|---|---|---|
| threshold_set | 二值化阈值 | 0~255 | 60 | 1 | SW12=10（模式2） |
| sobel_threshold_set | Sobel 阈值 | 0~2040 | 512 | 64 | SW12=11（模式3） |
| target_set | 曝光目标亮度 | 0~255 | 100 | 8 | SW12=00（模式0）且 SW3 低 |

- **sobel 阈值域说明**：寄存器 11bit，实际比较用 mag8 域（>>3）——步进 64 = mag8 域每 tick +8，长按响应明显。
- **教训**：声明初值与复位分支必须一致（历史上声明 512、复位 128，上板复位后阈值过低致边缘全白+噪）。

#### 4.5.5 ae_set（自动曝光/增益）

- **功能**：手动（SW3 高）按键调曝光/增益；自动（SW3 低）按平均亮度闭环调节。
- **关键设计**：曝光值 r_ae_set 是**同一个寄存器**，手动自动共用，切换模式不跳变。
- **参数**：AE_MAX=3990（2×帧长-10）、AG_MAX=143（8x 档上限，0x2f 非法会花屏）；目标亮度可调（初始 100）、死区 ±16、每 10 帧调一次；自动模式曝光/增益按权重分批次交替调节。
- **跨域**：I_avg/I_adjust 像素域 → 内部打两拍同步。

#### 4.5.6 bin2bcd + seg7（数码管显示）

- **bin2bcd**：双 dabble 算法（shift-and-add-3）16 次移位，16bit 二进制 → 4 位 BCD（输入须 ≤ 9999）。
- **seg7**：8 位数码管动态扫描，seg_data[31:0] = {16'hFFFF, BCD[15:0]}（高 4 位灭灯占位），0xF 译码为全灭。
- **显示档**（按 S_mode）：0=曝光（SW3 高）/目标亮度（SW3 低）、1=增益、2=二值化阈值、3=Sobel 阈值。
- **教训**：wrapper 声明行曾被注释吞掉导致 BCD 线隐式 1bit——数码管显示「1FFFE」垃圾、按键调了不显示（已拆行修复）。

#### 4.5.7 uii2c + uicfgcs500_720p（摄像头配置）

- **uii2c**：I2C 主机（官方）。uicfgcs500_720p：上电后逐寄存器写表初始化 SC500 为 1280×720@60；初始化完成后响应曝光调节请求（I_ae_req）写曝光/增益寄存器。
- **uics500regAE**：曝光/增益寄存器换算（曝光值 → 寄存器组，增益 → ANA GAIN 表，SC500GainTbl）。
