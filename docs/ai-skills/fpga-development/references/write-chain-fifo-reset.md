# 写链 FIFO 帧复位坑与实锤（2026-10-28）

涂白水平错位（左侧物体涂白在右、右边界物体涂白在左）+ 花屏 + 采背景全屏白三大现象的两大根因，全在 video_in 写链的 FIFO 复位时机。

## ISP 输出流结构（事实基础）
- ISP 输出 = AXI-Stream 128bit：tuser = 帧头第 1 拍数据（非消隐期 vsync）、tvalid 每行断 ~370 拍（行消隐空洞）、tlast 未连给 video_in。
- 帧数据 172800 字（720 行 × 240 字），帧尾垂直消隐 ~49500 拍。

## 根因 1：复位挂 tuser（帧头数据拍）→ 帧头丢字 → 全帧卷绕错位
- 复位窗 = 展宽 8 拍（摄像头域）+ 打 3 拍同步 ≈ 11 拍，恰好覆盖帧头数据 → 帧头丢 11 字。
- 后果：第 1 批从第 12 字开始 → 全帧内容错位 11 字 = 58 像素并卷绕（帧尾批丢 240 字，tb 实测 dbg_wr_cnt=172560）。
- 现象指纹：平移+卷绕（左→右、右→左），酷似镜像。区分方法：tb 行首/行尾注入差异，看 ERAM 标记落位（行首注入→标记应在行首字 bit[3:0]）。

## 根因 2：帧尾检测用 tvalid 下降沿 → 行消隐空洞每行误触发
- 每行 tvalid 断 370 拍 → 下降沿每行触发一次帧尾复位 → 写链每行被打断 → DDR 内容错乱 → 花屏撕裂（上半新下半旧）+ 采背景全屏白（cur/bg 全屏差异）。
- 正确判据：tvalid 低电平持续 2000 拍（370 行空洞 < 2000 < 49500 帧消隐），每帧只触发一次。

## 正确复位方案（已验证零错位）
1. 帧尾判定：low_cnt 计数 tvalid 低电平拍数，==2000 拍判帧尾（valid=1 清零）。
2. 帧尾脉冲展宽 8 拍（摄像头域，1 拍脉冲直打 3 拍会漏采）→ 打 3 拍 → 下降沿锁存 fend_latched。
3. 等 600 拍（帧尾批写 240 拍 + grant 竞争余量，远小于消隐期）后发复位脉冲，复位后清锁存。
4. 不复位在帧头 → 帧头零丢失、帧尾批完整写 → dbg_wr_cnt=172800=0x2A300（下板数码管 A300 为铁证）。

## tb 模型三坑（tb_video_in 实测）
- soft_fifo_model 同步链/指针寄存器不 initial → 上电首帧 rdusedw=X 传染批触发（`rd_num>=240` 对 X 恒假）→ 真实 IP 上电全局复位清指针，模型需 initial 全部指针。
- S_fifo_rst 组合逻辑依赖 FIFO 自身 rd_num 判空 → 组合环（rst→rptr→rdusedw→rst）死锁 → 改用固定拍等待（600 拍）代替判空。
- 跨域 1 拍脉冲（75M 域 6.67ns）直接打 3 拍（100M 域 10ns 采样）会漏采 → 必须先展宽 8 拍。

## TD 增量编译验证
- 不删缓存也真重综合：TD 按源文件时间戳判定。验证 = 编译 log 出现 Stage 1.x 消息（增量跳过不会有）+ 产物时间戳晚于源文件修改时间。
- 下板铁证：数码管 A300（写满 172800）。
