# 图像噪声处理方案库（背景检测/边缘检测降噪，仿真验证过）

自然光/强光噪声、孤立噪点、远距离白点的 FPGA 处理方案清单。每个方案都有已通过仿真验证的原型（sim/ 目录）与资源账，集成时按收益/成本排序选用。

## 选型总纲（对症四类噪声）

| 噪声类型 | 对症方案 | 资源代价 |
|---------|---------|--------|
| 亮度高时像素波动大（自然光） | 差分阈值随亮度自适应（thr_adaptive） | 十几个 LUT |
| 孤立散点/远距离白点拉大外接框 | 块密度过滤（blk_density） | ~400 slice（144×10bit 计数） |
| 2-5 像素光斑团 | 双次 3×3 腐蚀级联（erode 链） | DRAM 行缓冲 ×2 级 |
| 背景单帧噪声方差大 | 背景 EMA 多帧平均（bg_avg_ema） | ~60 LUT（+DDR 读改写） |
| 边缘检测固定阈值随光照漂移 | 梯度自适应阈值（sobel_adapt_thr） | ~200 LUT |

调研来源（用户要求「查了方案再写仿真验证」）：星点分割 FPGA 专利 CN104835177A（局部均值自适应阈值 T=m+mid/2）、时间平均背景建模专利 CN103325124A（5 帧平均+中值预处理）、分块自适应阈值论文（block-based adaptive threshold）、Improved Canny FPGA 论文（轻量化 = 梯度均值 k 倍阈值）。

## 零除法器定点技巧（三式，按场景选）

1. **档位查表**：阈值档位用比较器链映射（avg<80→25、<140→40、<200→60、else 80）——非 2 的幂分界用 >= 比较链，别用移位取商。
2. **常数移位近似**：除数为帧内固定点数（921600≈2^20）时 mean = sum>>CNT_LOG2，常数误差（13.8%）在系数里吸收；CNT_LOG2 做成 parameter（tb 用 10 加速、实机 20）。位选择取段时参数化写 [CNT_LOG2+7 : CNT_LOG2]，逐段核对（+2/+3 段位写错 = 阈值炸到饱和）。
3. **乘法逆元**：(b-a)/5 ≈ (b-a)×205>>10（205/1024=0.2002，误差 0.1%）。有符号差分 9bit 足够（像素差 ≤255）；Verilog 位选择 [17:10] 对负数 = 向零截断（-4100>>10 取位 = -4 非 -5），误差 ±1 内可接受，别为它加修正常数。

## 模块细节与已验证结论

### thr_adaptive（12 项断言全过）
- I_avg 接 ae_set 全图平均亮度，输出 2bit 档位直连 bg_read 的 I_thr_sel。
- 检测模式下「亮度自适应档」优先于 SW1/SW2 手动档；原样模式不差分无需自适应。

### blk_density（6 项断言全过）
- 80×80 块（1280/16=80、720/9=80 整除），144 块 8bit 块号 = {行块[3:0], 列块[3:0]}；row/80 与 col/80 用比较链（80 非 2 的幂，移位取商是错的——col[10:7] 对 80 整除不成立）。
- 帧级流水：帧 N 计数 → 帧 N+1 应用有效图；**首帧有效图默认全 1**（无统计时不过滤）。帧末 fs_pulse 拍「锁存有效图（拍前 cnt）+ 清计数」同拍完成。
- 块阈值 5 点：孤立 1-2 点块被踢；真实目标块（手/人）点数远高于阈值不受影响。集成到 bbox_stat 时门控 min/max/sum/cnt 的 S_st_en 链。

### sobel_adapt_thr（6 项断言全过：暗/亮场景各 3 项）
- T = (sum>>20) + (sum>>22) + (sum>>23) + 8 ≈ 1.564×mean，10bit 加和再饱和 255（先加后饱和，别 8bit 逐项加）。
- 帧末锁存阈值（fs 在帧尾语义）、下一帧应用；cnt=0（全黑帧）回退默认 64 防除零。
- 验证账：噪声梯度 8/边缘 100 → 阈值 31，边缘 102/102 检出、噪声 0 误检；光照翻倍（16/200）→ 阈值自动升 50，效果不变。

### erode_1bit 级联（5 项断言全过）
- 级联 N 次 3×3 腐蚀 = 等效 (2N+1)² 结构元，吃 N 圈边界：双次吃 3px 噪点团；目标须 ≥(2N+1)×(2N+1) 才存活（4×3 目标双次腐蚀后消失是正确行为不是 bug）。
- 级联延迟账：每级 +1 行 +1 拍列延迟（见 sim-debug-methodology 的流式窗口对齐账）。
- 集成走 morph DRAM 化路径（双次腐蚀 = 水平 2 拍 ×2 + 垂直缓冲 ×2），行缓冲深 = 有效拍/级。

### bg_avg_ema（3 项断言全过）
- EMA：bg_new = (4×bg_old + cur)/5，单帧 DDR 读改写（采集窗口内逐像素读旧写新），无需缓存 4 帧；等效 5 帧算术平均、噪声方差降 ~5 倍。
- 集成注意：读旧背景与当前帧像素必须同拍对齐（复用 bg_read 读路径）；采集窗口场景静止（防抖期已保证），EMA 收敛 6 帧到背景真值。

## 集成顺序建议（收益/成本）

1. thr_adaptive（必做，零成本直击自然光噪声根因）
2. blk_density 进 bbox_stat（框的孤立远点）
3. sobel_adapt_thr（清晰度模式边缘）
4. erode 级联进 morph（光斑团，DRAM 行缓冲翻倍）
5. bg_avg_ema（DDR 读改写，工程量大，最后上）
