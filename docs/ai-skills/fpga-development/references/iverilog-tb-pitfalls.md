# iverilog 仿真 tb 编写坑（2026-11-02 噪声处理仿真实战）

写 tb 时先过一遍这些坑，别在时序语义上绕圈。

## 1. task 参数是「调用时求值」的快照
`check(name, blk_en === 1'b1)` 的 cond 表达式在**调用时刻**采样信号——若调用时数据还没更新（NBA 未执行），传进 task 的已经是旧值 0，task 内部再等拍也救不回。正解：task 传「期望值常量」，task 内部 `@(posedge clk); #1;` 延迟到 NBA 生效后再读信号与期望比较。

## 2. edge 是 Verilog 保留字
wire 命名避开 edge/tri 等保留字（iverilog 报 syntax error 在声明行）。用 edge_out。

## 3. 位选择 [MSB:LSB] 对负数 ≠ 算术右移
定点近似 (diff×205)>>10 写成 `W_d5_r[17:10]`：对负数这是「补码向零截断」（-4100 → -4），算术右移是 floor（→ -5）。误差 ±1 可接受时无所谓，精确对账时用 `>>>` 或先判符号。tb 期望值计算要按实际截断语义算，别按纸面公式。

## 4. 流式 3×3 窗口的行/列对齐
- 行缓冲（R_ln0/R_ln1）读窗口时，**中心列 = 当前列-1**（当前行中心像素在 R_cur_m 缓存 1 拍），上两行读 [C-1:C:C+1]（模行宽），不是当前列。列错位 1 拍是高频 bug。
- 输出行延迟 = 1 行（中心行 = 上一行缓冲）；级联 N 级：行延迟 +N、列延迟再叠 N 拍（下一级输入流已带延迟，其 R_cur 再缓存 1 拍 → 中心列 = 原始列 - 级数×1）。tb 捕获坐标按级联深度补偿，检查点行号/位号都要重算。

## 5. fs 脉冲位置与锁存拍
「帧 N 统计 → 帧末锁存 → 帧 N+1 应用」类模块，tb 的 run_frame 要把 fs 脉冲放在**帧尾**（数据注入完后），因为 RTL 的 fs 拍锁存的是拍前统计值；放在帧头 = 锁存空帧，阈值恒默认值，连锁 FAIL。

## 6. @(posedge) 后采样的 NBA 时序
put 任务里 NBA 赋值（row<=r）后，主线程立刻读信号看到的是**旧值**（NBA 未执行）；采样必须再等一个 posedge 或 #1。连续 put 之间主线程的阻塞赋值（vld=0）会与 put 内 NBA（vld<=1）在同一时间步交错——最终值取决于执行顺序，调试打印的中间值会乱，别拿它断案，只看「下一拍沿后」的值。

## 7. 反馈环 tb 场景要贴合真实语义
EMA 类「old<=obg 逐拍反馈」的 tb 会把「每帧 1 次更新」的真实语义变成「每拍更新」，收敛轨迹与期望全乱。真实集成里 old 来自 DDR 读回（上一帧值、帧内不变）——tb 里 old 保持常数（帧内不反馈），按「每帧 1 拍」注入。
