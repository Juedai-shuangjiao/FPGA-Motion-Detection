# 图像处理算法升级与噪声抑制（PH1P35 实时图像处理赛题）

## 边缘检测清晰度三件套（改进 Canny，仿真验证 4 场景全过，待集成 canny_top）

现状：canny_top 已是 4 方向 Sobel + NMS + 双阈值（1 像素细边缘），但「清晰度不够」三根因：①卷积只有 Gx/Gy 两方向，斜边响应弱；②双阈值「弱边缘直接丢弃（不做滞后）」→ 边缘断链；③阈值固定人工档 → 场景自适应差。方案与实现要点：

1. **8 方向 Sobel**：180°/225°/270°/315° 是 0°/45°/90°/135° 的负方向，绝对值相同——只算 4 组取最大（省一半硬件）。算子（窗口 a b c / d e f / g h i）：G0=(-a-2d-g)+(c+2f+i)、G45=(-d-2g-h)+(b+2c+f)、G90=(-a-2b-c)+(g+2h+i)、G135=(-b-2a-d)+(f+2i+h)；幅值 = max(|G0..G135|)、方向量化 = argmax（4 向 NMS 沿用）。
2. **行内滞后连接**：弱边缘（low≤mag<high）左右邻接强边缘则保留——1 行 1bit 移位实现（左邻 = 最终边缘打 1 拍、右邻 strong = 当前拍右邻 mag 比较），零 ERAM；滞后只能沿行传播，垂直方向强弱分段验证不了。
3. **帧级自适应阈值**：T = 1.564×mean(mag)（sum×25/cnt/16，或移位近似 sum>>20+sum>>22+sum>>23+8 对 1M 像素帧），帧 N 统计帧 N+1 应用、首帧默认 40，低阈值 = 高/2。

论文依据：FCIS2023《FPGA-Based Improved Sobel Operator Edge Detection》（OV5640，2→8 方向后边缘细节/连续性显著提升）、IEEE ICIBA2024《FPGA-based Improved Canny Edge Detection System》（OV5640：混合滤波+8 方向+自适应阈值）、湖北汽车工业学院 2023《基于改进Canny算法的噪声图像边缘检测》（自适应中值-高斯+Laplace增强+Scharr+Otsu，指标+24.8%）。

## 自然光噪声两件套（背景检测链，已集成下板验证，fuse12）

白天自然光致背景差分噪声多的两个对症修法：

1. **亮度自适应差分阈值**：平均亮度 avg 8bit（brightness_stat 输出，帧级慢变）跨域打 2 拍后查表：avg<80→阈值 25、80~139→40、140~199→60、≥200→80（直接替换 bg_read 的 I_thr_sel 档位源——SW1/SW2 手动档在检测模式被自适应取代）。暗场景阈值低（压噪声）、亮场景阈值高（抗漂移），零额外资源（3 比较器）。
2. **块密度过滤（bbox_stat）**：画面分 16×9=144 块（80×80 像素 = 2 字宽）；帧内计数各块前景点，帧末（fs_pulse）锁存有效图（块点数 ≥5）并清计数，下一帧统计累加器门控 && 块有效——孤立噪点/远处白点所在的稀疏块整块踢出框统计。实现要点：块号从拍 B 锁存的字地址派生（行块 = S_wr_addr_b[14:5]/80 用 9 档比较链，列块 = S_wr_addr_b[4:1] 即字/2），计数在拍 C（S_st_en_c 拍）入账、拍 D 累加时 S_wr_addr_b 保持本字；首帧全有效。资源实测仅 +190 slice（144×10 FF 计数 + 144 FF 有效图 + 比较链）。

## 背景 EMA 多帧平均（bg_avg_ema 原型仿真过，未集成）

bg_new = (4×bg_old + cur)/5，逐像素 DDR 读改写（单帧缓冲、无需 4 帧缓存），噪声方差降 5 倍。定点零除法器实现：(4a+b)/5 = a + (b-a)/5，差分 9bit 有符号 ×205（≈0.2）再算术右移 10——注意有符号位选择 [17:10] 是向零截断（-4100→-4）、算术右移是 floor（-5），两者差 1，tb 期望按实现语义推。

## tb 场景设计坑（边缘/梯度类）

- 阶跃细线只有端点响应：0→255 硬跳窄线的 Sobel 响应只在左右端点各 1 像素（沿线内部 G=0）——验证连续性/滞后传播用「边界线」（上半 0 下半 255，mag 沿线连续）或斜坡图案。
- 行收集寄存器位宽 ≥ 每行像素数：左移 | 新 bit 的收集写法在帧宽 > 寄存器位宽时，前部像素的 1 被逐位移出丢失、读出来全 0（静默丢位不报错）；症状 = 收集计数正常、探针有值、阵列全 0。
