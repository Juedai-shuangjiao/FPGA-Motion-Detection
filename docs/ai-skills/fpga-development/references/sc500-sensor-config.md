# SC500CS 摄像头寄存器配置要点（调亮度/增益/曝光）

来源：`板子资料/HX1P35A_Contest_202606/4_芯片手册/SC500摄像头/SC500CS_数据手册_V1.8.pdf`
（SmartSens 传感器，增益表在「表 2-3 增益寄存器控制」「表 2-4 模拟 gain」「表 2-5 数字 gain」）

## 增益寄存器（调画面亮度的关键）
SC500 增益分「模拟 gain」和「数字 gain」两组，优先调模拟：

| 类型 | 整数档寄存器 | 微调档寄存器 |
|------|-------------|-------------|
| 模拟 gain | 0x3e08 | 0x3e09 |
| 数字 gain | 0x3e06 | 0x3e07 |

**模拟增益整数档（0x3e08）按 2 的幂翻倍**：
- 0x03 = 1x
- 0x07 = 2x
- 0x0f = 4x   ← 官方 720p60 默认值（注释「4x analogue gain」）
- 0x1f = 8x

微调档 0x3e09：0x20 是基准，往 0x3f 调可小幅增加（如 0x1f+0x3f = 15.75x，接近上限 16x）。

**调亮度 = 改 0x3e08**。例：lab_ex1~3 各自目录的
`user_source/hdl_source/uics500_cfg/uics500reg_720p60.v` 里
`112: REG_DATA={16'h3e08,8'h0f};` 把 `8'h0f` 改成 `8'h1f` → 4x→8x，亮度翻倍。
改完必须重新 Compile All（约 14 分钟）+ 下载才生效，不能只下旧 bit。

注意：增益越高噪点越多（增益放大信号也放大噪声），够亮即可；模拟增益到 16x 上限后仍不够才动数字增益 3e06/3e07。

## 曝光寄存器
- 0x3e00 / 0x3e01 / 0x3e02 = 曝光时间。
- AEC/AGC 策略（数据手册）：曝光优先，曝光到上限后才调增益。曝光与增益第 N 帧写入、第 N+2 帧生效，建议帧开始后写入。

## SC500GainTbl.v（增益查找表）
`2_Example/32_cs500_mipi_hdmi/src/uics500_cfg/SC500GainTbl.v` 是「增益档位 → 16 位寄存器值」映射表（如输入 64 → 输出 0x0F20，即 4x）。lab_ex 里 AG 调节（ae_set 模块）经它换算后写入增益寄存器。

## 「画面暗」排查路径（lab_ex 采集直通实测）
现象：能出画面但很暗，无论光源，出厂程序也暗。

1. **先看 OSD 暗不暗**（画面上的安路 Logo / 计数器文字，是 FPGA 直接生成、不经过摄像头）：
   - OSD 亮、只有摄像头画面暗 → HDMI 输出正常，问题在**摄像头采集**这条线。
   - OSD 也一起暗 → HDMI 输出 / 显示链路问题（查显示器 HDMI 黑电平、RGB 有限/全范围、亮度）。
2. **强光直射镜头**（台灯/手电）：
   - 变亮 → 曝光/增益在正常工作，只是「配置偏暗」→ 调增益（改 3e08）。
   - 不变 → 曝光/增益没生效，查寄存器写入 / 摄像头硬件 / FPC 接触。
3. 对照实验：显示器接电脑显示电脑相机画面清晰 → 排除显示器（显示器本身好）。

实测结论：lab_ex 官方 720p60 只给 4x 增益补偿短曝光，室内偏暗属正常，不是 bug。
