# 竞赛演示视频脚本编写法（选题二评分点导向）

适用：给 FPGA 竞赛作品写演示视频脚本/解说词（提交视频、答辩 demo 都适用）。

## 步骤
1. **先读官方评分材料**：比赛文件目录（D:\Users\user\Desktop\FPGA比赛\比赛文件\）里选题指南的「评分标准」节——脚本镜头按评分点组织，每个镜头标注覆盖的评分点（基础要求 1~4 / 基础扩展 1~2 / 高阶挑战 1~5）。选题二评分点：基础=MIPI采集+HDMI显示/基础算法/OSD+安路Logo/稳定性；扩展=风格化视觉增强/目标检测识别；高阶=多算法切换与状态显示/动态跟踪与坐标叠加/延迟可视化(帧号)/硬件运动目标检测/自动曝光优化。
2. **分镜表格式**：每镜头 = 动作（具体到拨哪个开关、按哪个键、镜头拍什么特写）+ 解说词（口语化、用户照念）+ 时长 + 「要点」（标注覆盖的评分点）。时长总目标 4~5 分钟，宁稳不赶。
3. **演示动作必须从源码核实，绝不凭记忆写**：拨码/按键语义从 sw_mode.v、motion_detect.v（mode_now）、hdmi_mixer.v（S_bbox_mode）、auto_manual_sel.v（en 条件）、wrapper（S_mode 调节对象）grep 核实。记忆会过期记错——本会话差点把 SW34 拨法写反，靠查代码纠正。
4. 结尾附「录制后检查清单」：Logo 全程可见（基础要求4必查）、每个功能画面 ≥5 秒、核心演示（手入画涂白）≥10 秒、OSD 数字变化有特写、无花屏黑屏、时长/命名/分辨率要求。

## 选题二已知拨码语义（写脚本直接用，改代码后重核）
- KEY4 短按=算法切换（原样/灰度/二值/Sobel），长按 200ms=自动/手动曝光切换（仅 SW34=00）
- SW1/SW2=KEY2/KEY3 调节对象：00 曝光/目标亮度、01 增益、10 二值阈值、11 Sobel 阈值
- SW3/SW4=画面功能模式：SW4 拨下=采背景+涂白检测；SW3 拨下+SW4 拨上=外接框+质心；都拨下=区域填充；00=自动模式
- 术语「背景减除法」非「帧差法」（评分/简介一致）
