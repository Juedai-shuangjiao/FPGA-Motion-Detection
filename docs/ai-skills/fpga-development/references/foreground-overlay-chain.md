# 前景标记叠加链：外接框/质心/跟踪 实战账（PH1P35 主线）

一切「挂在涂白链上的新绘制功能」（外接框、质心十字、方向块、后续区域填充）共用本账。

## 数据流

```
摄像头 → video_in 写 DDR → 消隐期 bg_read 读 cur/bg 两帧做差 → morph 开运算
       → 攒 40bit 字写 ERAM（前景标记，40bit×23040 = 45 块）
统计侧（DDR 域 100M）：bbox_stat 挂在 bg_read 写流上（写地址自带行号）
       → 框四边界 + sum_x/sum_y/cnt → 帧末半帧锁存 + A/B 合并
       → 恢复余数除法质心 → 帧间差分 = 速度向量 → 8 方向量化
       → 打 2 拍跨域（100M→75M）送 hdmi_mixer（值每帧才变，直接打拍即可）
绘制侧（HDMI 域 75M）：hdmi_mixer 与涂白 mark_comb 严格同相位绘制
```

## 统计侧设计（bbox_stat.v）

- **挂写流而非 4px/拍流**：写三件套（wr_en/addr/data）中地址自带行号（addr>>5 = 行、addr%32 = 行内字），每 10 拍处理一次，坐标推导零额外计数。写拍语义：addr = 本字实际写入 ERAM 的地址（bg_read 注释实锤）。
- **统计链流水必须是「A 组合 → B 锁存 → C 乘加 → D 累加」四拍结构，乘法输入必须用拍前寄存器**（时序修主，勿拍回单拍/单链）。原实现「popcount 树 + 位号和链 + 6×11 乘法 + 30bit 累加」全在一拍 = 16 级 LUT、13.6ns 违例（实锤两次：第一次 SWNS -3.87ns/49 条全在 S_sum_x 链；第二次乘法输入误用组合 S_pop/S_bit_sx 而非拍B寄存器，add46 违例 -3.331ns）。正确拆法：拍A = popcount/最低最高置位位号/位号和（~8 级 LUT）；拍B = 统计项锁存（_b 寄存器）；拍C = S_prod_x <= S_pop_b × S_wr_xbase_b + S_bit_sx_b（乘法输入全用 _b，~8 级）；拍D = 单次累加 + min/max 更新（门控 S_st_en_b 再打 1 拍成 S_st_en_c）。**乘法输入的组合→寄存器替换会让数据流整体晚 1 拍**（同块非阻塞拍前采样语义），累加器门控必须同步延 1 拍，否则累加用旧 prod 错位一字。**帧边界安全账**：fs 脉冲在写流静默 512 拍后到达，流水早已排空，无丢字——挂「写流静默后才发帧脉冲」的数据源时流水深度随便加。**定位法**：final_timing.rpt 的 Max Paths 头两条看 Begin/End Point 模块 + Logic Level——Level>12 且 End 在自己新模块 = 组合串拍拆拍；net 占比 >50% = 布局扰动（phys_opt/重布局，RTL 无用）。
- **半帧点数饱和 + 位宽瘦身**：半帧前景点数超 32768 即饱和（sum/cnt 停、min/max 继续 → 框保持完整），位宽从 30/31 压到半帧 26/25、整帧合并 27/26（32768×1279=41.9M < 2^26）。tb 场景注意：饱和阈值按「半帧」算——矩形目标必须整帧 < 32768 才不会在单半帧饱和。
- **除法器位宽变化会翻转 done 顺序**：DW 改后 done_x/done_y 谁晚谁变——帧间差分拍必须跟随较晚的 done，否则采样到旧商。
- **分组零重复（通用规则：交界行只由前段统计）**：两半帧版 A 半写 0~5887、B 半写 5632~23039 → B 半过滤 addr>=5888。三段版（黑线修复后）A 段 0~7935（248 行）、B1 段 7680~15615、B2 段 15360~23039 → B1 过滤 addr>=7936、B2 过滤 addr>=15616（干净区起点 = 段首字地址 + 重叠行数×32 字，重叠 8 行）。I_half_sel 两半帧版 1bit、三段版 2bit——融合两半帧统计模块进三段主线时逐项改：过滤阈值按段查表、锁存组 2 组扩 3 组、合并改三段。
- **帧边界锁存**：I_fs_pulse（bg_read 的 S_fs_d512）拍锁存「上一段统计」到 S_frame_seg 拍前值对应的组（读不满帧 seg 不翻转也正确），统计清零，S_frame_seg <= I_half_sel（本段类型）。整帧合并 = 最近 A + B1 + B2 三段锁存（每帧更新）。
- **三段合并必须拆两拍**：三输入 27bit 加法 + 四值嵌套三元比较一条组合链实测 13.6ns 超 10ns（net 占 55%）。拆法：拍1（fs_pulse）中间寄存器锁存 A+B1 双输入加/双值比较；拍2（S_latch_out）第二级 +B2 → R 锁存。除法被除数/除数改从 R 锁存取（I_numer 寄存器稳定，div_start 拍序不变）。
- **长链函数必须树化，别写 40 输入 if-加优先级链**：bit_sum_x 的 `for(i=0;i<40;i++) if(w[i]) s=s+i` 是 40 级优先级结构，实测违例（SWNS -1.023ns 落在 S_bit_sx_b 寄存器）。修法：8 组×5 输入组内链 + 三级括号加法树（`((s0+s1)+(s2+s3))+((s4+s5)+(s6+s7))`，组内 4 级 + 树 3 级 = 7 级）。popcount 类同理（TD 有模式识别常自动树化，位号和/加权和类自定义函数不会——写完先看时序报告确认该函数是否上了违例榜再改）。
- **位宽账（溢出必查）**：饱和制（半帧 32768 点上限）：半帧 sum_x ≤ 32768×1279 = 41.9M → 26 位；sum_y ≤ 23.5M → 25 位；整帧合并 ≤ 65536 点 → sum_x 27 位/sum_y 26 位；cnt 整帧 ≤ 65600 → 17 位（存储用 20 位无妨）。不用饱和制则整帧上限 sum_x ≤ 720×Σ(0..1279) ≈ 5.89e8 → 30 位、sum_y ≈ 3.31e8 → 31 位。
- **除 0 保护**：cnt < MIN_CNT（如 100）不启动除法——0/0 商出 X，会污染帧间差分链（prev/方向全部跟随 X）。无目标帧输出保持旧值、O_valid=0 屏蔽显示。
- **除法启动拍 = 锁存后 1 拍**：帧开始拍非阻塞锁存段统计、合并组合拍后才稳定——fs 拍直接启动采样的是旧合并值（晚一帧），用 fs 打 1 拍的 S_latch_out 启动。合并拆两拍后启动拍不变（S_latch_out 拍 R 锁存第二级合并值，div31 下一拍采样已稳定）。
- 恢复余数除法（div31）：每拍移位减记商 1 位，DW+1 拍完成；启动后输入须保持稳定（帧末锁存值满足）。比较拆段（高 11 位 + 低 20 位）防大位宽比较被映射 DSP。⚠️ TD 不认 Quartus/Xilinx 风格属性（实测 `(* syn_dspstyle = "logic" *)` 无效、DSP 不减）——TD 正确属性名 = `dsp_style`（值 no/yes/auto，SWUG106 手册 4.2.10，`(* dsp_style = "no" *)` 模块级可用）。统计链的 6×11 小乘法也会被 TD 塞进 DSP 18×18（DSP 数虚增 +2 实锤），小乘法一律 dsp_style=no 走 LUT；大位宽比较/减法同样可挂该属性防映射。
- 帧间差分：vx = cx - prev_cx（12bit 无符号减法借位 = 负）。方向量化：|vx|≥2|vy| → 水平（±15）；|vy|≥2|vx| → 垂直；否则对角（±10）；速度 <2 判静止 dir_valid=0。

## 绘制侧对齐账（hdmi_mixer.v，仿真实锤，勿回退）

- 涂白 mark_comb = fg_data[col_d1]，fg_data 的字来自「上一拍地址」（ERAM 读 1 拍）→ 位组合 = (word 打 1 拍, col 打 1 拍)。
- **绘制坐标必须用 word_d1 + col_d1 同拍组合**：word 与 col_d1 各自打 1 拍后在 col 回绕拍仍严格同步；直接拿未打拍的 word 配 col_d1 会在回绕拍超前 40（word 已进位、col 未回绕），框/十字每 40px 字边界错 1 拍。
- **垂直同理**：mark_comb 的字 = 上一拍地址的行 → S_yr 用 y_2d 打 1 拍。
- **坐标零补偿**：统计值从 bg_read 写流地址推导 = ERAM 位号域，绘制直接与位号比较 → 框边与同位号涂白同拍同位置，与中间相位账（S_fg_col 初始 26 补偿、DDR 读延迟 30 拍等）无关——结构自洽，别自造补偿常数（本会话曾误加 -26 补偿导致框偏移，去掉后与涂白精确同相位）。
- 输出优先级：osd > txt > bbox（框红 2px/十字绿 17×17/方向块黄 5×5）> 涂白 > video。使能 = 模式 3（SW3 拨下 && SW4 拨上）&& fg_init && bbox_valid。

## tb 验证法（tb_hdmi_mixer）

- **两轮对照验证同相位**：轮 1 模式 2 收集涂白竖条的显示 x 范围；轮 2 模式 3 收集框/十字/方向块范围；断言框边界 == 涂白边界（而不是绝对像素位置——绝对位置依赖 26 补偿等中间账，同相位才是本质）。
- ERAM 模型：reg 数组 + 读延迟 1 拍（NOREG 语义），竖条图案 = 每行字 4/5 全 1（mi%32==4||5）。
- **收集窗口避开 OSD 文字区**：OSD 恒显白字（组名/曝光值等）会被误收进白色统计——收集条件加 y 窗口（如 250~450）避开顶部文字区和底部名单行。
- 收集 N 帧则像素计数 ×N（断言按帧数换算）。
