## LED/数码管显示语义（用户偏好，非调试态）

- **LED1~4 = 模式指示 one-hot**：模式 0→LED1 亮、模式 1→LED2、模式 2→LED3、模式 3→LED4（每个模式只亮一盏，不用二进制码）。用户口头表述「模式1 led1亮，以此类推」就是这个意思——先确认 one-hot 意图再动手，别默认二进制码。
- **数码管按模式显示功能值**：模式 0=曝光（手动）/目标亮度（自动）、1=增益、2=二值化阈值、3=Sobel 阈值。调试档（写计数/锁存位）只在排障期临时占用，解决后清理回正式语义（生命周期见 sim-debug-methodology.md「下板诊断读数陷阱」第 4 条）。
- 拨码物理极性与代码注释可能相反——下板说明按「板上物理拨向」写，让用户报 8 位数码管从左到右全部数字。

## 初值/参数调整的落点

- 曝光/增益初值在 ae_set.v 有 8 处（r_ae_set/r_ag_set 声明初始化 + 复位分支 + r_ae/r_ag 声明初始化 + 复位分支）——改初值必须 grep 旧数值全文件对齐（1990/80 这类字面量），漏一处 = 复位瞬间跳回旧值。
