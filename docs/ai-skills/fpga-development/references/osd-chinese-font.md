# OSD 中文字模渲染与行布局（PH1P35 项目）

## 字模渲染参数（已定，勿再猜）

项目 OSD 字模（osd_cn_char.v）用 **微软雅黑 Bold（C:\Windows\Fonts\msyhbd.ttc）17px** 渲染，PIL 画布 16×16，draw 起点 (0, -4)。新字直接按此模板生成：

```python
from PIL import Image, ImageDraw, ImageFont
font = ImageFont.truetype('/mnt/c/Windows/Fonts/msyhbd.ttc', 17)
img = Image.new('1', (16, 16), 0)
d = ImageDraw.Draw(img)
d.text((0, -4), ch, font=font, fill=1)   # 起点 (0,-4) 是关键，别用 0,0
# 逐行打包 16'hXXXX，bit15=最左
```

## 新字必须与旧字同字体同参数（用户两次纠错的教训）

- 用户对字体不一致极其敏感：「字体还是不对」「新加的字和本来就没有对齐」——Serif 渲染、Sans 15px 渲染都被打回
- 正确流程：**先反推旧字模渲染参数，再渲染新字**。反推方法 = 字体匹配实验：拿一个已有字模（如「组」）的位图当基准，多字体 × 多字号 × 多偏移 × ttc index 组合渲染同字，按位 AND 计分取最高（匹配到 78/128 即确认，次优 Noto 系列只有 49-53）
- 候选字体按此顺序试：Windows 中文字体（msyh/msyhbd/simhei/simsun）→ Noto Sans CJK → Noto Serif CJK
- **字体统一的终点是全量重渲**：只重渲新字仍会「两种字体」——用户拍板后把全部旧字模（本工程 66 字）用同参数重渲一遍才是彻底统一。批量重渲脚本：正则提取每个块 `(\d)'d(\d+): begin  //(.)` 的索引+字 → 渲染 → 只替换块内 `O_row_bits = 16'hXXXX` 数据行（保留前缀/注释/结构，0-31 用 5'd、32-63 用 6'd、64+ 用 7'd）
- 块注释多字符坑：正则按「//字」提取时，「//（左括号」这类注释只匹配到「（」后必须用「//（」前缀定位块而非完整注释行；定位失败要检查实际注释格式而不是重试同一模式

## 字模索引编码与位宽坑

- 编码：S_txt_char = 8'h80 + 索引（bit7=1 表示中文，走 osd_cn_char ROM；bit7=0 为 ASCII）
- osd_cn_char 的 I_idx 原 [5:0]（0-63）——索引用到 64+ 时**必须同步扩三处**：I_idx 改 [6:0]、case 里 64/65 写 7'd64/7'd65（写 6'd64 会被截断成 6'd0，iverilog 只给 warning 不报错）、hdmi_mixer 例化 .I_idx(S_txt_char[6:0])（漏改则 64/65 截断为 0）
- osd_cn_char 的索引 0-31 用 5'd 格式、32-63 用 6'd 格式（grep 索引用 -E "(5|6|7)'dNN" 才不漏）

## OSD 行布局（改行内容前必查全局，避免重合）

行号 → Y 区间 → 内容（720P 视频域）：

| 行 | Y 区间 | 内容 |
|---|---|---|
| 0 | 640-656 | 组名 |
| 1 | 664-680 | 完成时间 |
| 2 | 10-26 | 曝光值 |
| 3 | 34-50 | 增益值 |
| 4 | 10-26（顶部居中） | 算法名 |
| 5 | 98-114 | 阈值 |
| 6 | 58-74 | 帧号（恒显） |
| 7 | 122-138 | 目标亮度 |
| 8 | 74-90 | 功能提示（已采-功能名，按 SW3/4 模式） |

规则：加新行/挪行前先列全行布局表——「功能提示行与阈值行重合」是直接照「帧号下方」硬塞 Y 74-90 撞上阈值 82-98 造成的；每行高 16px、x 起点 AE_AG_X。S_row_idx 扩 4 位后行号 0-15 可用。

**挪行三处联动（本次踩坑）**：改某行 Y 区间必须同步改三处——行注释、`if((S_y_2d >= 12'dX) && (S_y_2d < 12'dY))` 条件、`S_txt_row = S_y_2d - 12'dX` 减数。本次注释和减数改了、if 条件没改（字符串替换与真实代码格式不符静默失败）→ 行仍占旧区间与其他行重合。规则：用字符串替换改 Verilog 时，每处 replace 必须检查是否真发生（返回前值对比或事后 grep 新值），替换串要含 if 条件里的附加谓词（如 `((S_algo_mode_2d == 3'd2) || ...) && (S_y...)`）而不是纯 Y 片段。

## 行内容修改的三步验证

1. 改完 hdmi_mixer + osd_cn_char 后跑联合编译：`iverilog -g2012 -o /tmp/chk -y . -y key -I . osd_cn_char.v hdmi_mixer.v`，error+warning 全清
2. 查重复 default（sed 看 case 尾部）——sed 盲替换 idx 分支时容易把 default 复制一份
