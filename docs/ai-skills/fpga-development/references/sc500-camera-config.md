# SC500CS 摄像头配置要点（增益/曝光调节 + 画面暗排查）

数据手册：`板子资料/HX1P35A_Contest_202606/4_芯片手册/SC500摄像头/SC500CS_数据手册_V1.8.pdf`（增益寄存器在表 2-3/2-4/2-5，约第 23-26 页）。

## 增益寄存器编码（模拟增益 = 主调节手段）
- **0x3e08 = 模拟增益整数档**：0x03=1x、0x07=2x、0x0f=4x、0x1f=8x（2 的幂翻倍）。
- **0x3e09 = 模拟增益微调**：0x20=基准，0x20~0x3f 在整数档基础上小幅增加。查表：0x1f+0x20=8x，0x1f+0x30=12x，0x1f+0x3f=15.75x。
- **0x3e06/0x3e07 = 数字增益**（模拟增益到上限 16x 后才用，一般用不到）。最大支持 16x 模拟 + 32x 数字。
- 原则：**增益越高噪点越多**（暗部出现颗粒感），够亮就行，别一味拉高。比赛优先环境补光，增益做辅助。

## 官方 lab_ex 默认配置与调节
- lab_ex1/2/3 的 `user_source/hdl_source/uics500_cfg/uics500reg_720p60.v` 默认 **4x**（3e08=0x0f, 3e09=0x20），室内偏暗。
- 调节只改两行（约第 112-113 行）：
  - 4x→8x：`3e08 从 0x0f 改 0x1f`（3e09 保持 0x20）
  - 8x→12x：`3e09 从 0x20 改 0x30`（3e08 保持 0x1f）
- 改完必须 Compile All 重新编译（约 14 分钟）再下载，每个 lab_ex 各自有一份 uics500reg_720p60.v，要分别改。
- 增益寄存器的映射查找表在 `2_Example/32_cs500_mipi_hdmi/src/uics500_cfg/SC500GainTbl.v`（AG 值→16 位增益码）。

## 画面暗的排查经验（定位是摄像头还是显示链路）
1. **电脑相机对照**：把「板子 HDMI → 显示器」换成「电脑 HDMI → 同一台显示器」，若电脑画面清晰 = 显示器没问题，问题在板子端。
2. **OSD Logo/文字亮度**：lab_ex3 的「安路 Logo + 计数器」是 FPGA 直接生成的（不经过摄像头）。若 Logo 亮、只有摄像头画面暗 → HDMI 输出正常，问题在摄像头采集（曝光/增益）；若 Logo 也暗 → HDMI 输出/显示链路问题。
3. **强光直射镜头**：画面变亮 = 曝光/增益工作正常，只是配置偏暗；不变 = 增益没生效或摄像头硬件/FPC 问题。

## 相关背景
- SC500 是 SmartSens（思特威）传感器，MIPI 2Lane RAW10。
- AEC/AGC 策略（数据手册原话）：曝光时间优先，曝光到上限后才加增益。
- lab_ex 的 ae_set 模块支持按键调曝光/增益，但调节按键 I_button 接的是 GPIO 扩展口 N2/J14（非板载 KEY1~4），默认无按键，调不了。
