# HDL 入门教学要点（教用户从零写模块）

用户是 HDL 初学者（刚会流水灯/分频/testbench），2026 嵌赛 FPGA 赛道（安路 PH1P35 图像处理）。教用户写 HDL 时按这套来。

## 教学方式（用户明确偏好，务必遵守）
- **不写孤立练习题**：用户原话「也不是出题，最好是我亲手敲出来的代码最后能用上」。每个练习都必须是比赛真实要用的模块（按键消抖、灰度化、二值化、多算法切换、帧差法），写完最终例化进 lab_ex 工程上板。不要出「写完就扔」的题。
- **一步一步来**：用户会中途喊停问单个概念（parameter 是啥、always 是啥、为什么打两拍），逐个讲透再往下，别一次倒一堆。
- **给思路不代写**：给模块接口 + 功能要求 + 边界用例 + 各 always 块分工，让用户自己敲。testbench（验证工具）可以代写。
- **用 C 类比但点明本质区别**：用户有 C 基础，会用 C 类比学 Verilog，但必须反复强调「Verilog 并行 vs C 顺序」「事件触发 vs 循环」这两个根本区别，否则会写出错误心智模型。

## 练习模块路线（从比赛需求倒推，由浅入深）
1. key_debounce 按键消抖（打两拍 + 计数消抖 + 边沿检测）—— 多算法切换地基
2. 多算法切换骨架：按键短按切换状态机 + MUX（用「按键切换 LED 显示模式」灭/常亮/慢闪/快闪模拟）
3. 灰度化 + 二值化（移位运算，多算法切换的另两个算法通道）
4. 行缓存 3×3 窗口（Sobel/中值滤波基础）
5. 帧差法运动检测（进阶项 4）

> ⚠️ 方向修正：安路赛题进阶项（1）只要求「**短按**切换算法」，长按/短按区分是易灵思赛道做阈值调节才用的。用户明确「以比赛为主，比赛怎么用按键就往那方向努力」——练「短按切换」（多算法切换），别练长按。多算法切换骨架 = key_debounce（消抖脉冲）→ 模式计数器（按键脉冲+1 循环）→ MUX/case 按编号选输出。

## 按键消抖 key_debounce 参考实现（4 块 always）
接口参数 `CLK_FREQ` / `DEBOUNCE_MS`，端口 `clk`/`rst_n`/`key_in`/`key_pulse`。四块分工：
- 块① 打两拍同步：`key_d1 <= key_in; key_d2 <= key_d1;`（防亚稳态）
- 块② 消抖计数：`key_d2==0 && cnt<CNT_MAX` 则 `cnt+1`，`key_d2==1` 则清零
- 块③ 消抖标志：松开→`debounced=0`，`cnt==CNT_MAX`→`debounced=1`
- 块④ 边沿检测：`key_pulse <= debounced && !debounced_d`（debounced_d 是 debounced 打一拍）

`CNT_MAX = CLK_FREQ * DEBOUNCE_MS / 1000`。testbench 用 `#(.CLK_FREQ(25_000_000), .DEBOUNCE_MS(2))` 覆盖参数加速仿真（2ms 消抖，20ms 内跑完）。三个测试场景：抖动过滤（快速翻转不触发）、正常短按（触发一次）、长按（只触发一次），用 `always @(posedge key_pulse) $display` 数触发次数判定。

## 初学者核心混淆点（本会话实测踩坑）
1. **花括号 `{}` 不是代码块**：Verilog 模块体直接写在 `module...endmodule` 之间，不用 `{}` 包裹。`{}` 是位拼接运算符。代码块用 `begin...end`。用户会本能套 C 的 `{}`，是第一个要纠正的。
2. **非阻塞 `<=` vs 阻塞 `=`**：时序逻辑用 `<=`，右边全用「这一拍开始时的旧值」算、这一拍结束一起更新左边（`key_d2 <= key_d1` 里 key_d1 是旧值，这才实现延迟两拍）。用 `=` 会让两拍退化成一拍。
3. **打两拍 = 双级同步器消亚稳态**：异步信号（按键）随时变，可能正好卡在时钟沿被采到中间电平（亚稳态），打两拍给它两个周期稳定。任何片外异步输入进时钟域前都要先打两拍，是标配肌肉记忆。
4. **parameter vs localparam**：parameter 例化时可被 `#(.名(值))` 覆盖；localparam 模块内私有不可改。C 类比：parameter ≈ 带默认值形参，localparam ≈ const 常量。
5. **always 不是循环**：是事件触发，敏感列表条件发生一次执行一次（C 类比中断服务函数）。多个 always 并行 = 多块硬件电路同时通电，不是顺序执行。
6. **always 里没赋值的 reg 自动保持上一拍值**（寄存器有记忆），不用写 `xxx <= xxx`。
