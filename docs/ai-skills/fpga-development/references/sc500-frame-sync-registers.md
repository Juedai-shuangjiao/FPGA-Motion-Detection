## 曝光/增益帧同步（撕裂根因的关键）

- 数据手册 2.2.2 AEC 控制说明：**「曝光时间及增益若在第 N 帧写入，第 N+2 帧生效」** —— 曝光/增益本来就是帧同步的，切换发生在帧边界，理论上不该撕裂。
- 写入点建议「帧开始之后写入」。
- 曝光寄存器是 **20 位**：`{0x3e20[3:0], 0x3e00[7:0], 0x3e01[7:0], 0x3e02[7:4]}`，步长 1/2 行，最小值 3，最大值 = 2×帧长-10（720p60 帧长 VTS=2000 → 3990）。
- 调节步长 1/2 行时间（一行时间算 2.5 章节）。

## AGC 手动控制前提（米联客驱动漏了它 → 撕裂根因）

- 数据手册 2.2.3：「SC500CS AGC 控制方法：将寄存器 `16'h3e03` 的 Bit[3:0] 设置为 `4'hb`」。
- 这是让增益进「手动控制 + 帧同步生效」的前提。**不设 0x3e03=0xb 就裸写增益寄存器，模拟增益（0x3e08/0x3e09，模拟电路）会立即作用到当前帧** → 滚动快门「上下亮度不一致」撕裂。
- 米联客驱动（uicfgcs500 + uics500regAE）整个没写 0x3e03（grep uics500_cfg 目录只有 3e00/01/02/08/09），所以撕裂一直存在。
- 根治：曝光表写增益前先写 `0x3e03 = 0x0b`（uics500regAE 的 REG_SIZE 5→6，加一行 `3: REG_DATA={16'h3e03,8'h0b}`）。
- 曝光（数字寄存器）本身 N+2 帧生效不撕裂，撕裂的是增益；两者同一帧写入、同一帧生效（N+2）。

## 增益寄存器（表 2-3/2-4）

- ANA GAIN 0x3e08、ANA FINE GAIN 0x3e09、DIG GAIN 0x3e06、DIG FINE GAIN 0x3e07。
- 模拟增益档位：0x03=1x / 0x07=2x / 0x0f=4x / 0x1f=8x，FINE 微调 0x20~0x3f（0x20~0x3f 对应 1.0~1.97x 微调）。
- **0x2f 不是合法档位**（写入花屏），>8x 靠「0x1f 档 + FINE 微调」实现，最高约 14.75x（数据手册标称 16x 模拟增益）。
- 优先调模拟 gain，到上限再调数字 gain。DIG FINE GAIN 精度 1/128。
- 特性：16x 模拟增益、32x 数字增益、滚动快门（Rolling Shutter）、2-lane MIPI RAW10、500 万像素。

## Group Hold（原子 + 帧同步更新一组寄存器，更精细控制）

数据手册 2.3 GROUP HOLD。把一组寄存器打包、在一帧特定时刻统一生效；最大 4 组 group、共 320 寄存器、每组默认 16 个。

- 寄存器 `0x3800`（状态控制，Bit[7:0]，X=0~3）：
  - `0x0X` 开始打包到 group X
  - `0x1X` 结束打包到 group X
  - `0x6X` group X 寄存器「立刻生效」（第 N+1 个帧内生效时刻）
  - `0x4X` group X 寄存器「延迟 N 帧后生效」
- 寄存器 `0x3817`（帧延迟控制，Bit[3:0]）：写 0=不延迟、写 N=N 帧延迟（生效时间帧延迟）。

用法（调节曝光/增益想原子帧同步）：`0x3800 写 0x0X` → 写曝光/增益寄存器 → `0x3800 写 0x1X` 结束打包 → `0x3800 写 0x6X`（立刻）或 `0x4X`（延迟 N 帧）触发生效。

## 撕裂 vs 花屏（两种现象，别混）

- 撕裂 = 上下亮度不一致（增益/曝光切换瞬间，滚动快门下同一帧上下用不同值）。根因可根治（设 0x3e03=0xb 让增益帧同步）。
- 花屏 = 数据错位（画面乱掉），切换瞬间摄像头输出一整帧异常数据写进 DDR。靠 video_in 跳帧保护根治（I_ae_cfg_done 对齐 + 跳 3 帧）。
- 撕裂帧是「切换那一帧」，跳帧从下一帧开始、罩不住；花屏帧是「切换之后」，跳帧能罩住。
